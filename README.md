# নাজমা মেনশন — ওয়েব অ্যাপ

একটি সম্পূর্ণ স্ট্যাটিক (HTML5 + CSS3 + Vanilla JavaScript) মোবাইল-অ্যাপ স্টাইলের ওয়েবসাইট। কোনো ব্যাকএন্ড বা ফ্রেমওয়ার্ক নেই — সরাসরি Vercel-এ ডিপ্লয়যোগ্য।

## ডিজাইন

- পুরো সাইট একটি মোবাইল অ্যাপের সমান প্রশস্ততায় (৪৩০px) বাঁধা — ডেস্কটপেও এটা মাঝখানে ছোট একটা "অ্যাপ" এর মতো দেখাবে, মোবাইলে পুরো স্ক্রিনজুড়ে দেখাবে।
- একদম উপরে স্ক্রলিং ঘোষণা বার, তার নিচে হেডার, তারপর হোমপেজে বিকাশ/নগদ অ্যাপের মতো আইকন-গ্রিড।
- ব্যাকগ্রাউন্ড সাদা রাখা হয়েছে।
- লাইট/ডার্ক মোড টগল আছে (উপরে ডানে চাঁদ/সূর্য আইকন)।

## ফোল্ডার স্ট্রাকচার

```
নাজমা-মেনশন/

├── tenant-registration.html    ← ভাড়াটিয়া নিবন্ধন (গুগল ফর্ম এমবেড)

├── notices.html                ← নোটিশ বোর্ড
├── complaints.html             ← অভিযোগ / কমপ্লেইন
├── emergency.html               ← জরুরি যোগাযোগ
├── house-rules.html            ← বাড়ির নিয়মাবলী

├── js/common.js                ← মেনু + হোম-গ্রিড রেন্ডার, ডার্ক/লাইট মোড
└── js/calculator.js            ← বিদ্যুৎ বিল ক্যালকুলেটরের হিসাব-নিকাশ
```

## ★ নতুন ফিচার যোগ করার সিস্টেম

নতুন কোনো সেবা (যেমন: পানির বিল) যোগ করতে মাত্র **দুইটা কাজ** করতে হবে:

**১. `js/features.js`-এ একটা এন্ট্রি যোগ করুন:**
```js
{
  id: "water-bill",
  label: "পানির বিল",
  href: "water-bill.html",
  icon: '<path d="M12 2s6 7 6 11a6 6 0 1 1-12 0c0-4 6-11 6-11Z"/>'
}
```

**২. `water-bill.html` নামে একটা নতুন পেজ বানান** — সবচেয়ে সহজ উপায়, বিদ্যমান কোনো সাধারণ পেজ (যেমন `house-rules.html`) কপি করে ভেতরের `<main>...</main>` অংশের কনটেন্ট নিজের মতো বদলে ফেলুন। হেডার, ফুটার, মেনু, থিম — সব আগে থেকেই কাজ করবে।

ব্যাস! হোমপেজের আইকন-গ্রিড আর তিন-ডট স্লাইড-মেনু — দুই জায়গাতেই নতুন ফিচারটা **স্বয়ংক্রিয়ভাবে** যোগ হয়ে যাবে, কারণ দুটোই `js/features.js` থেকে জাভাস্ক্রিপ্ট দিয়ে তৈরি হয় (`js/common.js`-এর `renderMenu()` ও `renderFeatureGrid()` ফাংশন)।

আইকনের জন্য নতুন SVG পাথ [heroicons.com](https://heroicons.com) বা [feathericons.com](https://feathericons.com) থেকে (শুধু ভেতরের `<path>`/`<circle>` অংশটুকু) কপি করে ব্যবহার করতে পারেন — `viewBox="0 0 24 24"` ধরে রাখলেই আকার ঠিক থাকবে।

## অন্যান্য এডিটযোগ্য অংশ

### ঘোষণা টিকার
প্রতিটি HTML ফাইলে `<div class="ticker__text">…</div>` অংশের ভেতরের লেখা বদলে দিন (ফাইন্ড অ্যান্ড রিপ্লেস দিয়ে সব পেজে একসাথে বদলানো যাবে)।

### গুগল ফর্মের লিংক
`tenant-registration.html`, `rent-payment.html`, `complaints.html` ফাইলে `YOUR_GOOGLE_FORM_ID` জায়গাগুলো নিজের গুগল ফর্মের লিংক দিয়ে বদলে দিন।

### ফোন নম্বর ও ঠিকানা
`emergency.html`, `contact.html`, `rent-payment.html`, ফুটার-এ থাকা `01XXX-XXXXXX` আসল নম্বর দিয়ে বদলান।

### রঙ ও ফন্ট
`css/style.css`-এর `:root { ... }` অংশে সব রঙ CSS ভ্যারিয়েবল আকারে দেওয়া আছে — এখান থেকে বদলালে পুরো সাইটে পরিবর্তন হয়ে যাবে। ফিচার-গ্রিডের আইকন-টাইলের রঙ `.tile-1` থেকে `.tile-8` ক্লাসে (৮টা রঙ পালাক্রমে বসে)।

### অ্যাপের প্রশস্ততা
`css/style.css`-এ `--app-width:430px;` বদলে অ্যাপ-শেলের সাইজ ছোট/বড় করা যাবে।

## বিদ্যুৎ বিল ক্যালকুলেটরের হিসাব

```
মূল এনার্জি কস্ট = প্রগ্রেসিভ স্ল্যাব অনুযায়ী (getEnergyCost ফাংশন, js/calculator.js)
গড় প্রতি ইউনিট দাম = মূল এনার্জি কস্ট ÷ মোট ব্যবহৃত ইউনিট
জনপ্রতি ভ্যাট      = মোট ভ্যাট ÷ মোট ব্যবহারকারী সংখ্যা
এনার্জি বিল (প্রতি ফ্ল্যাট) = ব্যবহৃত ইউনিট × গড় প্রতি ইউনিট দাম
চূড়ান্ত বিল (প্রতি ফ্ল্যাট) = এনার্জি বিল + জনপ্রতি ভ্যাট
```

মূল মিটারের মোট ইউনিট এবং সব ব্যবহারকারীর প্রবেশ করানো ইউনিটের যোগফল না মিললে একটি সতর্কবার্তা দেখানো হয়। "প্রিন্ট বিল" / "ডাউনলোড PDF" বাটন ব্রাউজারের প্রিন্ট ডায়ালগ খোলে — সেখানে **Save as PDF** বেছে নিলেই বিল PDF আকারে সংরক্ষিত হয় (কোনো এক্সটার্নাল লাইব্রেরি ছাড়াই)।

## Vercel-এ ডিপ্লয় করা

1. এই পুরো ফোল্ডারটি একটি GitHub রিপোজিটরিতে আপলোড করুন।
2. [vercel.com](https://vercel.com) → "Add New Project" → রিপোজিটরি সিলেক্ট করুন।
3. Framework Preset-এ **"Other"** নির্বাচন করুন — কোনো বিল্ড কমান্ড লাগবে না।
4. Deploy চাপুন।

CLI দিয়ে: ফোল্ডারের ভেতরে গিয়ে শুধু `vercel` কমান্ড চালান।

## নোট

- কোনো npm/build step নেই — যেকোনো স্ট্যাটিক হোস্টিং (Vercel, Netlify, GitHub Pages)-এ কাজ করবে।
- লাইট/ডার্ক মোড ব্যবহারকারীর ব্রাউজারে (`localStorage`) মনে রাখা হয়।
